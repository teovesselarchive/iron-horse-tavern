# Iron Horse Tavern

<!-- impeccable:product-schema 1 -->

## Platform
web

## Purpose
An independent restaurant website concept that helps guests choose a meal, make a reservation, order, visit either branch or plan an event. The active redesign scope is Iron Horse Tavern only, across all 11 HTML pages. A separate public GitHub repository is the requested delivery destination.

## Stack
Portable static HTML, CSS and JavaScript. Shared styles and interactions load first; assets/horse.css and assets/horse.js implement the current replacement identity and homepage interactions.

## Capabilities and constraints
Preserve accurate branch information, menu access, reservations, ordering, event inquiries, parking, maps, accessibility and social routes. Official external services handle transactions; there is no local booking or inquiry form. Do not fabricate bookings, submissions, prices, reviews, ratings or venue history.

The homepage contains a restaurant-led photographic hero, local story, real-dish sampler, happy hour, room gallery, private events, brunch, branch-specific visit information and a complete family/footer area. The user requested 4–6 real dishes. The current five are Giant Bavarian Pretzel, Tuna Poke Nachos, Cubano, Stuffed French Toast and Honey Truffle Pizza: four photographic choices plus the pizza text feature. All 11 routes retain useful service links.

## Brand commitments
Retain the official name and logo, real venue/food photography and accurate Sacramento/Folsom context. The replacement world uses brick red, cream, leather and copper with Alfa Slab One and DM Sans. Apply the user's quality bar with an independent venue identity, clear text-only actions, responsive compositions, keyboard access and reduced-motion support. The earlier condensed-type newspaper/kimchi direction was rejected. The user also rejected the origin slogan in the hero; use the restaurant name and a concrete description of the food, cocktails and R Street room. Venue-space photography must show R Street only.
